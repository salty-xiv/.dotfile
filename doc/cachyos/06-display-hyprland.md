# Hyprland

Hyprland needs some secondary things to manage taskbar and locking. also including a file explorer and dmenu since they
are used in the config

```bash
# hypridle # idle manger for hyprland
# hyprlock # locker screen for hyprland
# hyprshot # screenshot tool
# nautilus # file explorer
# rofi # dmenu
# swaync # notifications
# waybar # taskbar like
# wpaperd # wallpaper tool
sudo pacman -S hypridle hyprlock hyprshot nautilus rofi swaync waybar wpaperd
```
