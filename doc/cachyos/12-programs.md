# programs

Programs that need minor to no setup are grouped here

# social media

```bash
# discord # social media
sudo pacman -S discord
```

# video/audio/text

```bash
# gimp # photoshop
# libreoffice-still # office program
# obs-studio-browser # streaming program
# vlc # video player
sudo pacman -S gimp libreoffice-still obs-studio-browser vlc
```

# util

```bash
# gparted # gui partition tool
# tree # tool to show folders in cli
# geany # basic text editor
sudo pacman -S gparted tree geany
```

# AUR

uses paru

```bash
# parsec # remote
# streamcontroller # util for streamdeck
# synology-drive-client # client to sync with synology nas
paru -S parsec
paru -S streamcontroller
paru -S synology-drive
```
