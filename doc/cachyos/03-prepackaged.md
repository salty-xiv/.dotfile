# prepackaged

cachyos comes with some tools prepackaged. This is a list of tools I used on other systems and don't need to install. noting them in case cachyos stops prepacking them.

```bash
paru # aur downloader

git # git cli
unzip # for zip files
alacritty # terminal
zsh # alt shell for bash
firefox # browser
parted # partition disk management
udisks2 # disk mounting tool
dolphin # file explorer
pavucontrol # audio device manager

curl # curl
wget # basic curl like tool
bat # better cat
tealdeer # tldr aka cli documentation util
fd # fuzzy find
fzf # fuzzy find
ripgrep # fuzzy find
gcc14 # gcc for nvim
```
